# next steps, in order:
1. **Move the logic out of the views into `PlayerModel`.** Right now `PlaybackControlsView` mutates `playheadPosition` and `isPlaying` directly. Give the model methods like `togglePlay()`, `seek(to:)`, `next()`, `previous()`. The lock-screen commands will need to call the same functions as your buttons, so the model should be the single place where playback logic lives.
2. **Give `PlayerModel` an `AVPlayer`** and make `isPlaying` / `playheadPosition` reflect the player rather than drive it. A periodic time observer (`player.addPeriodicTimeObserver(forInterval:queue:using:)`, say every 0.5s) updates `playheadPosition`.
3. **Fix the slider/observer fight.** Once the time observer writes `playheadPosition`, dragging the slider will fight it. The usual pattern is an `isScrubbing` flag. Set it from the slider's `onEditingChanged`, ignore observer updates while it's true, and call `seek(to:)` once on release instead of on every drag tick.
4. **Add the audio file to `Song`.** There's currently no way to know *which* file to play. Store a *relative* filename (e.g. `"abc123.m4a"`) and resolve it against the Documents directory at play time. Don't store a full URL, because the app container's path can change between launches and reinstalls, which would break every saved song. This is also exactly what the downloader will write later, so it's good groundwork.
5. **Then** the audio session, background mode, now-playing info and remote commands from my earlier list. One catch: remote command handlers aren't guaranteed to run on the main actor, and `PlayerModel` is `@MainActor`, so inside a handler do `Task { @MainActor in self.togglePlay() }` and return `.success` immediately.

## smaller things:
- `ContentView` has an unused `playSong(_:)` and `modelContext`, and no list of songs yet, so you can't pick a track from the UI. A `@Query` over `Song` in a `List` is the SwiftData-idiomatic way once you're ready.
- The repo has no `.gitignore`, so `xcuserdata/` (including your username folder) is committed. Adding the standard Xcode/Swift `.gitignore` and running `git rm -r --cached` on those folders cleans that up.
